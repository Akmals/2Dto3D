# 2D to 3D Converter

The project is a 2D to 3D converter. Users can take a 2D image/drawing and Convert to 3D Model

Currently a Work in progress. 

Future Plans:
- more robust pin point precision when outlining
- Ability to split and combine different layers
- lighting fixes
- Mesh creation and Mesh convertability
- download Final OBJ file
- Color Wheel and Mapping
- and more features

Current Issues:
- lighting shining from middle of object
- when viewing and unviewing layer, entire object dissappears
- Download final Object box missing
- merging of faces of different layers not working
- adding multiple layers not working
- sizing increases size but cannot decrease size
